📋 PASOS PARA INICIAR LA APLICACIÓN:

1. INICIAR XAMPP
   ✓ Abre XAMPP Control Panel
   ✓ Inicia Apache (botón Start)
   ✓ Inicia MySQL (botón Start)

2. CREAR LA BASE DE DATOS
   ✓ Abre tu navegador
   ✓ Ve a: http://localhost/phpmyadmin
   ✓ Haz clic en la pestaña "SQL"
   ✓ Abre el archivo: backend/database/schema.sql
   ✓ Copia TODO el contenido
   ✓ Pégalo en el área de texto de phpMyAdmin
   ✓ Haz clic en "Continuar"
   ✓ Verifica que se creó la base de datos "servicios_db"

3. INICIAR LA APLICACIÓN ANGULAR
   
   OPCIÓN A - Usando el archivo batch:
   ✓ Haz doble clic en: iniciar-app.bat
   
   OPCIÓN B - Manualmente:
   ✓ Abre una terminal/CMD
   ✓ Navega a: cd c:\xampp\htdocs\Frameworks\Angular\servicios-app
   ✓ Ejecuta: ng serve --open

4. ACCEDER A LA APLICACIÓN
   ✓ La aplicación se abrirá automáticamente en:
     http://localhost:4200

🎯 CÓMO USAR LA APLICACIÓN:

PARA CLIENTES:
1. Inicia sesión o regístrate como "Cliente"
2. Explora los servicios disponibles
3. Usa los filtros por categoría o búsqueda
4. Haz clic en "Contratar" en el servicio que te interese
5. Completa la fecha y mensaje
6. ¡Listo! El proveedor recibirá tu solicitud

PARA PROVEEDORES:
1. Inicia sesión o regístrate como "Proveedor"
2. Haz clic en "Mis Servicios"
3. Crea un nuevo servicio con el botón "Nuevo Servicio"
4. Completa todos los datos:
   - Título descriptivo
   - Categoría apropiada
   - Descripción detallada
   - Precio y tipo (hora/servicio/día)
   - Ubicación donde ofreces el servicio
   - URL de imagen (opcional)
5. ¡Tu servicio estará visible para todos!

⚠️ SOLUCIÓN DE PROBLEMAS:

❌ "No se puede conectar a la base de datos"
   → Verifica que MySQL esté corriendo en XAMPP
   → Verifica que la base de datos "servicios_db" exista

❌ "Error CORS" o "No se pueden cargar los servicios"
   → Verifica que Apache esté corriendo en XAMPP
   → Verifica que los archivos backend estén en:
     c:\xampp\htdocs\Frameworks\Angular\backend

❌ "ng no se reconoce como comando"
   → Instala Angular CLI: npm install -g @angular/cli
   → Reinicia la terminal

❌ La página no carga
   → Verifica que el servidor esté corriendo (ng serve)
   → Abre: http://localhost:4200 manualmente
