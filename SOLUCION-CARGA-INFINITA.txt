❌ PROBLEMA:
El botón de login muestra el spinner de carga pero nunca termina.

🔍 CAUSA:
El backend PHP no está respondiendo o no está accesible.

═══════════════════════════════════════════════════════════════════

✅ SOLUCIÓN PASO A PASO:

PASO 1: VERIFICAR XAMPP
─────────────────────��──────────────────────────
1. Abre XAMPP Control Panel
2. Verifica que Apache esté en VERDE (corriendo)
3. Verifica que MySQL esté en VERDE (corriendo)
4. Si alguno está en rojo, haz clic en "Start"

PASO 2: VERIFICAR BACKEND PHP
────────────────────────────────────────────────
1. Ejecuta: verificar-backend.bat
   O manualmente:
2. Abre tu navegador
3. Ve a: http://localhost/Frameworks/Angular/backend/test.php
4. Deberías ver un JSON como:
   {
     "status": "success",
     "message": "Backend PHP funcionando correctamente",
     "timestamp": "2024-12-04 05:38:23"
   }

PASO 3: VERIFICAR BASE DE DATOS
────────────────────────────────────────────────
1. Abre: http://localhost/phpmyadmin
2. Verifica que existe la base de datos: servicios_db
3. Si NO existe:
   - Haz clic en "SQL"
   - Importa el archivo: servicios_db.sql
   - O copia y pega el contenido del archivo

PASO 4: PROBAR API DE LOGIN
────────────────────────────────────────────────
1. Abre tu navegador
2. Ve a: http://localhost/Frameworks/Angular/backend/api/categorias/read.php
3. Deberías ver un JSON con las categorías
4. Si ves un error, continúa al Paso 5

🔧 SOLUCIONES COMUNES:

PROBLEMA A: Apache no inicia
────────────────────────────────────────────────
CAUSA: Puerto 80 ocupado por otro programa
SOLUCIÓN:
1. Abre XAMPP Control Panel
2. Haz clic en "Config" (Apache)
3. Selecciona "httpd.conf"
4. Busca: Listen 80
5. Cámbialo a: Listen 8080
6. Guarda y reinicia Apache
7. Actualiza la URL en Angular:
   - Archivo: src/app/services/auth.service.ts
   - Cambia: http://localhost/
   - Por: http://localhost:8080/

PROBLEMA B: Error de conexión a base de datos
────────────────────────────────────────────────
CAUSA: Base de datos no existe o credenciales incorrectas
SOLUCIÓN:
1. Verifica en phpMyAdmin que existe: servicios_db
2. Si no existe, importa: servicios_db.sql
3. Verifica credenciales en: backend/config/database.php
   - Host: localhost
   - Usuario: root
   - Password: (vacío)
   - Base de datos: servicios_db

PROBLEMA C: Error CORS
────────────────────────────────────────────────
CAUSA: Headers CORS no configurados
SOLUCIÓN:
Ya están configurados en todos los archivos PHP.
Si persiste, verifica que los archivos PHP tengan
estas líneas al inicio:

header("Access-Control-Allow-Origin: *");
header("Access-Control-Allow-Methods: GET, POST, PUT, DELETE, OPTIONS");
header("Access-Control-Allow-Headers: Content-Type, Authorization");

🔍 DIAGNÓSTICO AVANZADO:

1. Abre la Consola del Navegador (F12)
2. Ve a la pestaña "Network" o "Red"
3. Intenta hacer login
4. Busca la petición a "login.php"
5. Verifica:
   - Status: Debería ser 200 (OK)
   - Si es 404: El archivo no existe o la ruta es incorrecta
   - Si es 500: Error en el servidor PHP
   - Si es 0 o "failed": No hay conexión con el servidor
